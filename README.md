## 📝 О проекте

**ClipMaker Studio** — это веб-приложение для создания анимированных клипов из изображений без необходимости в видеомонтаже. Загрузите фоновое изображение, добавьте анимированные слои (средний и ближний план), наложите фоновую музыку — и получите готовое видео с профессиональной анимацией.

Просто откройте в браузере и создавайте видео за минуты — никакой установки, регистрации или сервера не требуется.

## 🎮 Как пользоваться

### 1. Загрузите изображения
- **Фоновый слой** — изображение, заполняющее весь экран (опционально)
- **Средний план** — анимированный объект на фоне
- **Ближний план** — анимированный объект на переднем плане

### 2. Настройте анимацию
- Выберите **тип анимации** для каждого слоя
- Настройте **размер** слоя ползунком
- Отрегулируйте **общую скорость** анимации

### 3. Добавьте музыку
- Загрузите MP3, WAV или OGG файл для фонового сопровождения

### 4. Предпросмотр и экспорт
- Нажмите **▶️ Предпросмотр** — увидите анимацию в реальном времени
- Нажмите **🎥 WebM** — сохраните видео с музыкой (до 15 секунд)
- Нажмите **🎞️ GIF** — сохраните анимированный GIF (до 8 секунд)

> 💡 *Совет: для лучшего качества используйте изображения с прозрачным фоном (PNG) для среднего и ближнего планов.*

## 🎨 Типы анимации

| Тип | Эффект | Лучше всего подходит для |
|-----|--------|-------------------------|
| **Скольжение** | Плавное движение по диагонали | Логотипов, текстовых элементов |
| **Вращение** | Постоянное вращение вокруг оси | Звёзд, значков, иконок |
| **Подпрыгивание** | Мягкие вертикальные движения | Персонажей, акцентных элементов |
| **Пульсация** | Изменение размера (увеличение/уменьшение) | Кнопок, акцентов |
| **Парение** | Нежные колебания вверх-вниз | Облаков, абстрактных элементов |
| **Дрожание** | Быстрые микродвижения | Взрывов, вибрации |

## ⚠️ Известные ограничения

- **Длительность видео**: до 15 секунд (для производительности)
- **GIF экспорт**: до 8 секунд, 12 FPS (оптимизация размера файла)
- **Аудио**: только при экспорте в WebM (GIF без звука)
- **Размер кадра**: 1280×720 (фиксированный)
